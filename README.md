# Everafter Events

A modern and elegant event planning website designed to showcase celebrations, present event planning services, and help clients enquire about their special occasions.

## Overview

**Everafter Events** is a responsive frontend website concept for an event planning business. It features a clean layout, sophisticated typography, event photography, soft visual styling and interactive animations to create a professional online presence.

The website is designed to communicate creativity, thoughtful planning and seamless event coordination.

## Features

- **Responsive Design** – Adaptable layout for desktop, tablet and mobile devices.
- **Elegant Hero Section** – Clear introduction with prominent call-to-action buttons.
- **Event Planning Journey** – A visual timeline explaining the planning process.
- **Event Portfolio** – Image-based showcase of different event categories.
- **Contact & Enquiry Form** – Form layout for collecting client event requirements.
- **Scroll Animations** – Reveal effects for content and images as visitors scroll.
- **Soft Background Effects** – Subtle pastel blurred shapes for visual depth.
- **Navigation** – Simple navigation with links to the main website sections.

## Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `indexx.html` in your browser.

No build tools or framework installation are required.

## Customization

You can customize the website by editing:

- `indexx.html` – Website content and structure.
- `stylex.css` – Colors, typography, layouts, responsive styling and animations.
- Image files – Replace the sample event images with your own photography.

Update the contact email, phone number and enquiry form integration before using the website for a real business.
